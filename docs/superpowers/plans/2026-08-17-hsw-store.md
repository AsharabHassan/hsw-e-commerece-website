# HSW Store Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Turn the single static `index.html` product page into a working, self-hosted e-commerce store with a Postgres database, cart, Stripe checkout, customer accounts and an admin panel.

**Architecture:** One Express 5 process rendering Nunjucks templates server-side, talking to Postgres through a thin two-driver query layer (`pg` in production, PGlite in dev/test). No build step, no ORM, no client framework. nginx terminates TLS and serves `/public`; PM2 keeps the node process alive.

**Tech Stack:** Node 24, Express 5, Nunjucks, Postgres 16 / PGlite, Stripe Checkout, `express-session`, `zod`, `bcrypt`, `multer`, `helmet`, `node:test` + `supertest`.

**Spec:** `docs/superpowers/specs/2026-08-17-hsw-store-design.md`

## Global Constraints

- **Money is integer pence everywhere.** No floats in code, JSON, or the database. Format for display only, at the template boundary.
- **Prices are never trusted from the client.** The cart holds `{product_id, qty}` only; every total is recomputed from the database.
- **Orders become `paid` only via a signature-verified Stripe webhook.** The browser redirect back from Stripe sets no state.
- **Brand tokens are frozen** and must be copied verbatim from `index.html`: gold `#D4AF37`, ink `#1A1A1A`, muted `#4A4A4A`, bg `#FFFFFF`, bg-alt `#F8F8F8`, line `#E5E5E5`; dark `#050505` / `#0A0A0A` / `#FFFFFF` / `#9CA3AF`. Display font Playfair Display, UI font Montserrat. Buttons: 0px radius, 16px/32px padding, 600 weight, 1.6px letter-spacing.
- **Dark theme uses the `.dark` class on `<html>`**, persisted to `localStorage` under `hsw-theme` — same convention as the main clinic site.
- **Locale is en-GB, currency GBP.**
- **Seeded products carry `is_placeholder = true`**, which renders a visible badge and blocks add-to-basket.
- **All SQL is parameterised.** No string-built queries, ever.
- **Every state-changing POST carries a CSRF token.**
- Node's built-in test runner only: `node --test`. No Jest, no Mocha.

- [ ] **Step 5: Write `db/index.js`**

Selects the driver at first use. `pg.Pool` when `DATABASE_URL` is set,
otherwise PGlite persisted to `.data/pglite` (or in-memory when
`PGLITE_MEMORY=1`, used by tests). Both expose the same `query`/`withTransaction`.

```js
import config from '../config.js';

let impl = null;

async function init() {
  if (impl) return impl;
  if (config.databaseUrl) {
    const { default: pg } = await import('pg');
    const pool = new pg.Pool({ connectionString: config.databaseUrl, max: 10 });
    impl = {
      query: (text, params) => pool.query(text, params),
      withTransaction: async (fn) => {
        const client = await pool.connect();
        try {
          await client.query('begin');
          const out = await fn(client);
          await client.query('commit');
          return out;
        } catch (err) {
          await client.query('rollback');
          throw err;
        } finally {
          client.release();
        }
      },
      close: () => pool.end(),
    };
  } else {
    const { PGlite } = await import('@electric-sql/pglite');
    const dir = process.env.PGLITE_MEMORY === '1' ? 'memory://' : (process.env.PGLITE_DIR ?? '.data/pglite');
    const lite = await PGlite.create(dir);
    impl = {
      query: (text, params) => lite.query(text, params ?? []),
      withTransaction: async (fn) => {
        await lite.query('begin');
        try {
          const out = await fn({ query: (t, p) => lite.query(t, p ?? []) });
          await lite.query('commit');
          return out;
        } catch (err) {
          await lite.query('rollback');
          throw err;
        }
      },
      close: () => lite.close(),
    };
  }
  return impl;
}

export async function query(text, params) { return (await init()).query(text, params); }
export async function withTransaction(fn) { return (await init()).withTransaction(fn); }
export async function close() { if (impl) { await impl.close(); impl = null; } }
```

import { randomUUID } from 'node:crypto';

export async function freshDb() {
